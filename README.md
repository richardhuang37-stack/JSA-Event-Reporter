# JSA Event Reporter

JSA Event Reporter is a planned Java application for helping the Japanese Student Association (JSA) executive board organize events, coordinate responsibilities, and share progress.

## Background and purpose

Communication among JSA executive board members was sometimes unclear, especially around event scheduling, task assignments, progress check-ins, and which members would attend events. This project is intended to provide a centralized place to organize that information, make responsibilities easier to follow, and support clear event reporting.

## Planned core features

- Create and manage club events.
- Manage E-Board members.
- Assign tasks and deadlines to members.
- Track task completion and progress.
- Confirm which E-Board members will attend events.
- Generate event summary reports with event details, attendance, and outstanding responsibilities.

## Planned technologies

Java, JavaFX, Maven, JUnit, PlantUML, and Git/GitHub.

## Initial design

This project is at the initial design stage. The features and technologies above are planned; they have not been implemented. The initial application logic design is shown in [classes.puml](classes.puml).
